# Agent Instructions

Before making any implementation decision — writing code, creating files,
modifying existing files, choosing libraries, or structuring any feature —
you must first read the following two files in full:

1. `Spec.md` — the technical specification. This defines the data schema,
   architecture, business rules, API structure, and functional requirements.
   All implementation must conform to what is specified here.

2. `Design.md` — the UI design system. This defines every colour token,
   typography rule, component specification, screen layout, and build
   instruction. All UI implementation must match this exactly.

These files are the single source of truth for this project. Do not make
assumptions. Do not rely on defaults. Do not deviate from what is specified
in these documents, even if an alternative seems reasonable.

If something you need to implement is not covered by either document, stop
and ask before proceeding.
